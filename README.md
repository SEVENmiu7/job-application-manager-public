# 求职投递管理器｜公开多人版

一个可公开访问、登录后使用的求职投递管理工具。每位用户拥有独立的数据空间，只能查看、创建、编辑和删除自己的投递记录。

> 本项目使用独立的飞书妙搭应用和数据库，不连接作者的正式版、面试演示版或私人多维表格。新用户首次登录时数据为空，系统不会自动写入样例。

## 核心功能

- 五阶段投递看板，支持拖动推进、重点置顶、筛选和排序。
- 投递列表、搜索、分页、快捷修改和材料详情抽屉。
- 工作地点多选、地区搜索和自定义录入。
- 岗位链接采集与结构化信息提取。
- 求职流程时间线和阶段时间补录。
- 面试复盘、问题记录、改进方向和下一步行动。
- 个人数据可导出为 Excel 或 JSON，并支持删除当前账号的全部数据。
- 浅色、深色、跟随系统及多套强调色。

## 登录与数据隔离

- 应用允许公开访问，但必须登录飞书账号后才能使用。
- 后端从登录上下文取得当前用户 ID，不接受前端指定数据归属。
- 列表、详情、统计、看板、更新、删除和面试复盘均按当前用户 ID 查询。
- 数据库启用行级安全策略，只允许登录用户读写 `user_id` 与自己一致的记录；匿名访问被拒绝。
- 后端过滤与数据库策略共同形成两层隔离。
- 应用内不提供管理员查看全部用户记录的页面或接口。
- 隐私页面会说明数据托管边界，并提醒用户不要填写高度敏感信息。

## 空白账号体验

新用户首次登录会看到“还没有投递记录”的空状态，可通过“创建第一条投递”开始使用。删除全部记录后仍保持空白，不会恢复虚构数据。

## 技术栈

- React 19 + TypeScript + Vite
- NestJS 10
- PostgreSQL + Drizzle ORM
- Tailwind CSS + shadcn/ui
- 飞书妙搭 full-stack 运行时

## 目录结构

```text
client/     React 前端
server/     NestJS 后端、数据库结构与迁移
shared/     前后端共享类型
scripts/    本地开发和质量检查脚本
test/       自动化测试
```

## 本地开发

环境要求：Node.js 22+ 和 npm 10+。

```bash
npm install
npm run dev
```

妙搭本地开发需要由平台下发 `.env.local`。仓库仅提供不含密钥的 `.env.example`，不包含真实数据库连接信息。

## 公开仓库安全边界

仓库通过 `.gitignore` 排除 `.env`、`.env.local`、`.spark`、日志、依赖目录和构建产物。任何真实简历、投递记录、Token、密码、数据库地址、私人链接或应用密钥都不应提交到公开仓库。

公开多人版不提供以下能力：

- 与作者私人飞书多维表格同步。
- 附件上传和真实简历托管。
- 管理员查看用户数据。
- 跨用户协作或共享投递记录。

## 版本同步策略

正式版验证通过的通用功能可以同步到本项目，但每次都必须重新检查用户隔离和公开仓库安全。私人多维表格能力、手动同步代码、私人配置、环境文件、真实数据、附件和旧应用 ID 永远不进入公开多人版。

详细版本记录见 [`CHANGELOG.md`](CHANGELOG.md)，长期同步边界见 [`SYNC_POLICY.md`](SYNC_POLICY.md)。
